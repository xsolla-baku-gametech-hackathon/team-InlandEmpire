One shared crate: tappad-protocol

Holds the message types: CardUid, Cents, Sku, OrderId, PadEvent. Bridge, server, game and SDK all import it, so field names cannot drift. The firmware follows the same JSON shape by hand.

Two payment providers behind one interface

The server's PaymentProvider has two implementations: Xsolla and Mock. One environment variable switches them. Mock approves instantly after the registry check, so the whole demo runs offline.

Where things run

Firmware runs on the pad. Bridge, server and game are three separate processes on the player's PC. Xsolla is the only thing off the machine.
